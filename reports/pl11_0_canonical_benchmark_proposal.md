# ENNOVERA PL PHASE 11.0 — CANONICAL BENCHMARK PROPOSAL

- **Dataset:** 4 historical seasons (2022-23 to 2025-26), 1,520 matches.
- **Primary Metrics:** RPS (Ranked Probability Score), Multiclass Log Loss, Multiclass Brier, 3-Class Accuracy, Draw Recall.
- **Secondary Metrics:** Goals MAE, Clean-Sheet Brier, Scoreline Likelihood.
- **Prediction Cutoff:** `prediction_freeze_time < fixture_kickoff`.
