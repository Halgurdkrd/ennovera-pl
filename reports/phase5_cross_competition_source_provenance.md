# ENNOVERA PHASE 5.0 — DATA SOURCE PROVENANCE

## Target External Sources for Acquisition
1. **FBref (Sports-Reference):** Comprehensive match-level and player-level logs (minutes, starts, goals, assists, xG, xA, shots, progressive passes, tackles) for UCL, UEL, UECL, FA Cup, and League Cup.
2. **Understat:** Shot-level and match-level xG/xA logs for European competitions.
3. **Official UEFA API / UEFA Data:** Official lineups, kickoffs, substitutions, discipline, and match travel locations.
