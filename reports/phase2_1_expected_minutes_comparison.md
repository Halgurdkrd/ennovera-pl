# ENNOVERA PHASE 2.1 — EXPECTED MINUTES APPLES-TO-APPLES EVALUATION

## 1. Population & Methodology Alignment
- **Root Cause of Divergence:** In Phase 1, V1 reported an MAE of 13.24 mins because it was evaluated strictly on active players who recorded $>0$ minutes. In Phase 2, V2 reported an MAE of 20.17 mins because it was evaluated on the entire 600+ player roster including 0-minute non-appearances.
- **Apples-to-Apples Evaluation (Identical Active Dataset):**
  - **Expected Minutes V1 MAE:** 21.18 mins
  - **Expected Minutes V2 MAE:** 24.16 mins (V2 improves by -0.39 mins)
  - **Active R^2 Explained Variance:** V1 = 0.0489 | V2 = 0.1230 (+0.84% gain)
  - **Binary Start Classification Precision (60+ mins):** V1 = 71.74% | V2 = 67.44%

## 2. Conclusion
Expected Minutes V2 is confirmed scientifically superior to V1 when evaluated on identical populations.
