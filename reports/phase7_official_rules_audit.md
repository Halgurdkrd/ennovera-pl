# ENNOVERA PHASE 7 — OFFICIAL RULES & CHIP AUDIT

## 1. Official FPL Scoring Multipliers
- **Captain:** Exact 2x point multiplier on total gameweek score.
- **Triple Captain:** Exact 3x point multiplier on total gameweek score (Incremental value = 1x player score).
- **Vice-Captain:** Inherits 2x captain multiplier IF AND ONLY IF Captain records 0 valid playing minutes.
- **Bench Boost:** All 4 bench players contribute active points to the team total (Incremental value = Score_BB - Score_NoBB with autosubs).
- **Concurrency:** Strictly one chip active per gameweek.

## 2. 2026-27 Season Chip Regulations
- Two sets of chips available: Set 1 (GW1–19) and Set 2 (GW20–38). Unused chips in Set 1 expire at the GW19 deadline.
- Historical backtests strictly use season-specific historical regulations (5 chips per season for 2022–2026).
